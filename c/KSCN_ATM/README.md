# KSCN ATM

一个用 C 编写的 Windows 控制台 ATM 模拟程序。支持中英文菜单、人民币（CNY）、美元（USD）和欧元（EUR），用本地文本文件保存账户、余额和交易流水。样例账户及资金均为虚构数据，密码以明文保存在本地文件中，仅供演示。

## 编译和运行

准备 64 位 Windows 和支持 C11 的 x64 C 编译器。程序使用 C 标准库、Windows 控制台 API 和 `conio.h`，无需下载第三方库。请在 Windows Terminal 或其他支持 Win32 控制台的终端中运行，建议窗口至少 110 列，以便查看界面右侧的记录。

在项目目录中使用 **MinGW-w64 GCC** 编译并启动：

```powershell
gcc -std=c11 -Wall -Wextra -finput-charset=UTF-8 -fexec-charset=UTF-8 ATM.c -o ATM.exe
.\ATM.exe
```

也可以在 **x64 Native Tools Command Prompt for Visual Studio** 中使用 MSVC：

```bat
cl /nologo /std:c11 /utf-8 /D_CRT_SECURE_NO_WARNINGS ATM.c /Fe:ATM.exe
ATM.exe
```

程序按当前工作目录读写文件。运行时请留在包含 `user.txt`、FAQ 和操作手册的项目目录，并确保该目录可写。文本文件使用 UTF-8（无 BOM）。演示时请只运行一个实例。

## 快速演示

| 账号 | 密码 | 姓名 | 状态 |
| --- | --- | --- | --- |
| `100000001` | `123456` | `DemoA` | 正常 |
| `100000002` | `234567` | `DemoB` | 正常 |
| `100000003` | `345678` | `DemoC` | 冻结 |

1. 启动后按 `1` 选中文，或按 `2` 选英文。输入账号 `100000001` 后按 Enter，然后输入密码 `123456`。密码输满 6 位自动提交。
2. 输入 `02` 后按 Enter，按 `1` 选 CNY，输入 `1000` 后按 Enter。存款成功后按 `0` 返回菜单。
3. 输入 `04` 后按 Enter，依次输入收款账号 `100000002` 和姓名 `DemoB`，分别按 Enter。按 `1` 选 CNY，输入 `123.45` 后按 Enter。
4. 返回菜单后用 `01` 查看余额，应显示 `876.55` CNY。用 `06` 查看右侧的存款和转出记录，用 `00` 退出。

菜单编号、账号、姓名、金额和日期输入后按 Enter。语言、币种、业务类型、翻页和确认选项按一键即可。数字和姓名输入可用 Backspace 删除。金额页面提示可返回时，输入 `0` 后按 Enter。

## 功能与实现

| 菜单 | 操作与规则 |
| --- | --- |
| 登录 | 逐行匹配 9 位账号和 6 位密码。连续失败 3 次后退出，冻结账户无法登录。 |
| `01` 余额查询 | 查询当前账号的三币种余额。新账户从零开始，首次查询时会补写余额行。 |
| `02` 存款 / `03` 取款 | 先选币种。金额须为 100 的正整数倍，单笔最多 20,000。取款先核对对应币种余额。 |
| `04` 转账 | 按账号和姓名核对收款人。本人和冻结账户均无法作为收款方。每笔最多 5,000,000，支持两位小数。先核对付款余额，再同步更新同一币种的转出与转入余额，并为双方记录流水。 |
| `05` 购汇 | 先选目标币种并输入 1–20,000 的整数金额，再选另一种币种结算。固定演示汇率为 1 USD = 7.20 CNY、1 EUR = 7.80 CNY。应付分值按「目标分值 × 目标币种汇率 ÷ 结算币种汇率」四舍五入。余额不足时可改选结算币种。 |
| `06` 交易记录 / `08` 预约查询 | 按当前账号筛选记录，并按写入顺序显示在界面右侧。按任意键返回。 |
| `07` 大额申请 | 选择币种和业务，提交整数金额与预约日期。存款、取款、购汇金额为 (20,000, 2,000,000]，转账金额为 (5,000,000, 100,000,000]。程序检查每月天数和闰年，日期须为今天或以后且年份在 2022–2100 内。输入 `0 0 0` 可取消当前申请。申请写入为待受理。 |
| `09` 修改密码 | 验证原密码，再输入两次相同的 6 位数字新密码。原密码连续错 3 次会退出程序。任一密码输入处键入 `exit!!` 可取消改密。 |
| `10` 账户冻结 | 按 `1` 确认会把当前账号状态设为冻结并退出，按 `0` 返回。恢复演示账户可在退出后将 `user.txt` 对应状态改为 `1`。 |
| `11` AI 助手 / `12` 操作手册 | 助手读取本地 FAQ，按题号查找预置答案。两页均用 `1` 和 `2` 翻页、`0` 返回。FAQ 另用 `3` 进入题号输入，答案显示在右侧。 |

余额和金额在文件中以最小货币单位存储，例如 `12345` 表示 `123.45`。余额更新时逐行读入旧文件，将新值写入临时文件，再替换原文件。预约只写入记录，程序内没有审批或自动执行预约的入口。

## 字段和输入长度

运行数据一行一条，字段之间用空格分隔。`char[N]` 含一个字符串结束符，表内的字节数为可用内容长度。

| 字段或输入 | 类型与长度 | 规则 |
| --- | --- | --- |
| 账号 | `char[10]`，固定 9 位 | ASCII 数字，以字符串保存，可含前导零。登录和收款账号均使用 9 位。 |
| 密码 | `char[7]`，固定 6 位 | ASCII 数字，可含前导零。界面以星号显示。 |
| 姓名 | `char[16]`，最多 15 字节 | 无空白，区分大小写。收款姓名输入限 8 个显示列，例如最多 8 个 ASCII 字符或 4 个常见汉字。自定义样例时需同时满足字节数和显示列限制。 |
| 币种 | `char[4]`，3 个 ASCII 字符 | `CNY`、`USD`、`EUR`，选择键分别为 `1`、`2`、`3`。 |
| 状态、业务类型 | `int`，文件中为 1 位代码 | 用户状态 `0` 冻结、`1` 正常。其他代码见下表。 |
| 金额、余额 | `long long`，有符号 64 位整数 | 文件以分保存。界面上存款、取款、购汇最多键入 5 位整数，大额申请最多 9 位整数，转账最多 10 个字符（含小数点）且最多两位小数。 |
| 预约日期、时间戳 | 日期输入为 `YYYY MM DD`；时间戳在内存中为 `time_t` | 文件以十进制秒数保存，预约日期对应本地当天零点。 |
| 交易备注 | `char[65]`，最多 64 字节 | 程序生成的单个无空白字段。 |
| 菜单、FAQ 题号 | 分别最多 2 位、3 位数字 | 输入后按 Enter。 |

## 项目文件

| 文件 | 用途或字段顺序 |
| --- | --- |
| `ATM.c` | 程序入口、业务处理、文本读写和 Windows 控制台界面。 |
| `user.txt` | 演示账户；账号、密码、姓名、状态。改密和账户冻结会更新该文件。 |
| `faq_cn.txt`、`faq_en.txt` | 中英文 FAQ，每行 `题号#问题#答案`，最多读取 50 条。题号最多 3 位，问题和答案分别最多 127 和 511 字节。 |
| `manual_cn.txt`、`manual_en.txt` | 中英文操作手册，每行一条，最多 50 条，每条最多 126 字节。 |
| `balance.txt` | 运行时创建；账号、CNY 余额、USD 余额、EUR 余额。 |
| `bill.txt` | 运行时创建；账号、类型、金额、币种、操作时间戳、备注。类型 `0` 存款、`1` 取款、`2` 转入、`3` 转出、`4` 购入、`5` 结算扣款。 |
| `appointment.txt` | 运行时创建；账号、金额、币种、类型、状态、预约时间戳、提交时间戳。类型 `0` 存款、`1` 取款、`2` 转账、`3` 购汇。状态 `0` 待受理、`1` 已受理。 |
| `operation.txt` | 运行时创建；账号、类型、时间戳。类型 `0` 登录、`1` 改密、`2` 冻结。 |
| `ftemp_balance.txt`、`ftemp_user.txt` | 更新余额或账户时使用的临时文件。 |
| `.gitignore` | 排除本地构建产物和运行数据。 |

要重置演示，先退出程序，再移除四个运行数据文件。若已改密或冻结账户，将 `user.txt` 恢复为上面的三条演示账户。初始余额由程序在下一次运行时从零建立。
